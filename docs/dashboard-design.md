# Continuous dashboard

**THESIS:** one shared workspace, with the current inspection as the starting
point and dedicated pages for setup, inspection, session records and sources.
**OWN-WORLD:** the user-pinned Liquid Glass planner reference: black canvas,
Instrument Serif throughout (the latest user-selected preview), silver pill
actions and solid panels. Other stored font choices remain available.
**STORY:** see actual work and source state, choose a workflow, inspect and review,
then return without losing the view or draft.
**FIRST VIEWPORT:** a labelled left sidebar, quiet page header, compact icon actions,
then the current-scan summary beside acquisition activity. Recent session runs and
source configuration share an aligned supporting row. A selected saved
scan stays distinct from any other active run. Dataset catalog size describes
available inputs; finite batch progress belongs only to acquisition activity.
**FORM:** the user's supplied dashboard composition is the authority; no random
concept selection. The dominant image stays in the dedicated inspection page.

Scope: local research application, not a monitoring center with invented lanes,
throughput or safety decisions. Both dark/light modes and existing functionality
remain. Reference source files were read locally; no private planner records or
reference service capabilities are copied. The latest dashboard source and its
26 September preview were inspected. On phones, workflow actions form two columns;
inspection, activity, recent work and sources stack with the selected image visible.
Short labels accompany icons. Source details and Workspace notes expand on demand;
no-safety-decision and unverified-scanner statements remain visible. This usability
refinement preserves the selected Instrument Serif font and current palette.
