# Instrument Serif

Local font for the user-selected Liquid Glass dashboard. The user's latest
preview request applies it to all interface text, including controls and records.
Other fonts remain selectable in Appearance. No runtime font CDN is used.

These files contain regular and italic 400 only. The light-mode readability
preference uses browser-synthesized bold at CSS weight 600, not a separate or
modified Instrument Serif font file. Dark-mode weights remain unchanged.

Copied without modification from the user-supplied `scroll-eye` reference
package's `fonts/` directory on 26 September 2026. The copied bytes were checked
against that package's manifest. No media or private planner data was copied.

The included [OFL license](OFL.txt) identifies the
[Instrument Serif project](https://github.com/Instrument/instrument-serif).
These are the original supplied TTF files, not a newly downloaded or rebuilt
upstream release. Font copyright and redistribution terms remain in `OFL.txt`.
